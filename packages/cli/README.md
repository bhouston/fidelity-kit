# fidelity-kit

Toolkit for renderer fidelity suites: point it at a results folder and get metrics, delta images and a viewer website.

```sh
npx fidelity-kit process <results-dir>     # metrics + delta images + index.json
npx fidelity-kit serve <results-dir>       # serve the viewer
npx fidelity-kit build <results-dir> --out site/   # static export
```

See the [repository](https://github.com/bhouston/fidelity-kit) for the folder contract and full documentation ([docs/ADOPTING.md](https://github.com/bhouston/fidelity-kit/blob/main/docs/ADOPTING.md)).
